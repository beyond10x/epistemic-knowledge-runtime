## Decisions taken by the coordinator

- MCP lives in the binary (`crates/ekr/src/cli/mcp.rs`), hand-written JSON-RPC over stdio on the
  existing `serde_json`: no new crate, no new dependency, no async runtime (ADR 0006;
  `docs/predecessors.md:53`). Tools: search, describe node, expand neighbourhood, timeline,
  overview and explain, each returning the `ekr.views` or explain document unchanged; no write
  tool.
- The write-cost unit starts with a release profile of propose/validate/commit in one session and
  changes only what the profile names; invariant 1 (a candidate replay through the kernel
  authority before every native append) holds.
- The views baseline pins scenario names and counts, not the suite digest.
- `task:historical-projection-carries-the-head` (next wave) removes `head` from all six
  `ekr.views` formats and gives the viewer a head endpoint.
