## What is wrong

`b10x.docs.yaml` is the unified documentation site's manifest, generated by `atlas docs reconcile`.
This repository publishes its own site (`.github/workflows/pages.yml`, `b10x-docs-site.yml`; on
2026-10-07 `https://beyond10x.github.io/epistemic-knowledge-runtime/` answered 200 and
`https://beyond10x.github.io/docs/epistemic-knowledge-runtime/` answered 404). The manifest belongs
to the retired unified site and should go.

## Build

Delete `b10x.docs.yaml`, and the two planning references that name it as current
(`story:cli-user-documentation` lists it as a scope path; `docs/roadmap.md:126`).

## Order

The organisation's documentation procedure deletes a repository's unified-site files as the last
step of leaving the unified site, after Atlas, the organisation index, lists the repository as documented
independently. Deleting first once made the organisation portal refuse every pull request in the
organisation. Read on 2026-10-07 from Atlas `main` (`5a2c04e463`, 2026-10-05): its
independent-documentation roster names `uilab`, `canon`, `engineering-protocols`, `loom`,
`governed-autonomy`, `substrate`, `metaharness`, `secrets` and `llm`, not this repository, and its
catalog has no row for it. The website's data names it nowhere.

So this task waits on `dependency-blocker:atlas-lists-ekr-as-independent`.

## Acceptance

- `b10x.docs.yaml` is absent on `main`, and the organisation portal's pull-request check stays
  green across the organisation after it lands.
- `task site-check` exits 0.
