## Outcome

Import observations independently of canonical revisions and retain immutable typed interpretations with local schemas, source observation references, blockers and processing receipts. Repeated import returns the original receipt without duplicate records. Unmappable knowledge and rejected interpretations' source bytes remain inspectable after reopen.

## Boundaries

Reuse existing observation idempotency keys and GraphRoot/TransientGraph. Cited bytes are pinned; roots do not own observations. Exact document coordinates and digest envelopes avoid self-referential hashes. Validate local interpretation shape without requiring canonical mapping. No polling, checkpoints, GC, general retention reclamation or canonical observation-evidence admission in this story.

## Acceptance

Named implementation cases: observation_retry_is_idempotent; rejected_interpretation_retains_its_sources; unmapped_knowledge_survives_reopen. Cover native provider atomic failure/restart, content mismatch, immutable versions and inspectable exact bytes. Supply observe import and incubate import/list/show through CLI and typed SDK; viewer read presentation where relevant.

## Scope

Cited by scoper source inspection: crates/ekr-store/src/eventlog.rs object_append and atomic (independent BlobAppendGroup), crates/ekr-observe existing import/idempotency model. Inferred new retention port/child module and record types, crates/ekr-integrate local document validation, crates/ekr-kernel Runtime facade, crates/ekr CLI/session, crates/ekr-sdk transport methods and provider conformance tests. Store mutation remains reachable only through kernel, with architecture guards updated for legitimate ports.
