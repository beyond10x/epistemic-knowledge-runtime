# Public signed-answer transport

The source manifest identifies the tested changes over the published durable-answer checkpoint. Runtime, CLI/session and the typed SDK now submit generated AttentionAnswerApplication documents and return the generated AnswerReceipt. Attention history returns immutable generated HumanAnswerRecord values, optionally filtered by dispute. The CLI accepts bounded JSON from a file or stdin, decodes generated contracts, and delegates signature verification and publication to the kernel. It neither signs nor grants request-supplied authority. Documentation describes correction kinds, external review, exact retry and history. No specification or generated bytes changed.

The real SDK-to-session-to-CLI-to-kernel test runs on file and SQLite. It commits two evidenced competing claims, applies an independently signed authority upgrade, answers using a second external signature, checks the resolved receipt and empty inbox, retries without sampling the clock, filters immutable history, and repeats those reads/retries after full replay. Forged signatures, altered statements, invalid base64 and empty correction reasons refuse without adding history. Bounded-input tests reject malformed/oversized JSON and explicit null temporal bounds. The existing subprocess read-only suite now exercises answer refusal both directly and through a held session, while history remains readable.

Two implementation defects were exposed before correction. A changed retry was correctly rejected by storage but surfaced as an operational fault; attention dispatch now reports its PublicationInputConflict as the existing KnowledgeRefused. A redundant request basis with a negative revision passed the generated-data decoder, though publication still compared it with the signed basis; the decoder now checks that basis through the canonical review codec. session_red.txt and decoder_red.txt retain the failing assertions. The documentation guard now recognizes actual generated correction labels alongside graph-operation labels, so a correction named Retract is not mistaken for a nonexistent graph operation. Public-surface coverage includes direct generated application decoding.
