through ordinary guarded Propose, Validate and Commit. Source evidence is reused or linked to the
exact wrappers elected by the schema transaction. Mapping and derivation records are retained
with the frozen step, and Explain exposes those generated records only for verified commits.

describes the same verified prefix as its receipt even if a later mapping has already committed.
